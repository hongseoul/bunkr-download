Appearance

Discreet view

Discreet view Swaps previews and sensitive words on screen for something neutral. Files on disk are not touched. Toggle any time with CtrlShiftH.
Previews

Covered previews are not downloaded at all. Each file always gets the same picture.

Names
Sensitive words

Whole words, including words joined in camelCase (NsfwClips), so “class” or “Essex” stay untouched. Name cipher uses the same lists when it replaces sensitive words on disk.

Also match inside joined words Catches words glued together in one case, like “nsfwclips” or “NSFWCLIPS”. Stricter: parts of ordinary words get replaced too (“class”, “Essex”, “cocktail”).
Hold Alt to peek While Alt is held, the card under the pointer shows its real preview and name.
Blur the window when you switch away Covers the content whenever the app is not focused, including taskbar and Alt+Tab previews. Works even with Discreet view off.
Always start in Discreet view Otherwise the app opens the way you left it.
Show the toggle in the sidebar A small eye next to the theme dots. Turn it off to rely on the shortcut only.

Downloads

Retries per file How often a file is retried after a network error, rate limit (429) or server error. Interrupted files continue where they stopped.
Speed limit (MB/s) Total across all parallel downloads. 0 means unlimited.
Proxy http://host:port, https://host:port or socks5://host:port. Used for every request. Leave empty for a direct connection.
When Bunkr is under maintenance Wait and retry a few times, or skip the file and let you retry later.
Check free disk space Refuse to start when the selected files clearly will not fit.

Disk check

Re-download size mismatches When Check disk is on, files whose local size differs from the expected size are downloaded again.
Disk checks only read the chosen local folder — file names, sizes and a few header bytes. Nothing is uploaded or hashed to a cloud index. Thumbnails load with no-referrer, so album URLs are not leaked to the CDN.

Name cipher

Replace a word in created names Applies to the album folder and file names this app creates (case-insensitive).
Replace sensitive words in saved names Every word from the Discreet view lists becomes a neutral word (e.g. “maple”) in folder and file names on disk. The same word always gets the same replacement.

Album search

Search site The album index that Search reads. Change it if the site moves to a new domain; leave empty for the default.
Only your search words are sent to this site. Results link straight to bunkr albums, and their thumbnails load with no-referrer.
